# 逐光 · 夸父逐日

> 剪影风神话跑酷：化身夸父，追一轮永不可及的太阳

> 北方有神，名曰夸父，不量力，欲追日影。

在剪影风的荒原上化身夸父，追一轮永远追不上的太阳：拾日光升倍率、掬甘泉续冲刺、撞碎旱魃与金乌、神力满时一步跨过整屏，在身后的长夜吞没你之前跑得更远。

和一般的无尽跑酷不同——天地会跟着《山海经》的记载一路走完：拂晓启程、饮于河渭、道渴而死、弃杖化为邓林。越过终章还没有完，邓林月夜与大荒星野只有跑得够远的人见得到。

## 支持范围

| 方面 | 支持情况 |
| --- | --- |
| **设备** | 桌面（键盘）· 手机 / 平板（屏上触控按钮）。竖持会提示旋转横屏以获得完整视野 |
| **浏览器** | 构建目标 ES2022——Chrome / Edge 94+、Safari 15.4+、Firefox 93+ |
| **安装** | 不需要。打开网页即玩，无下载、无账号、无注册 |
| **联网** | 游戏全程在你浏览器里跑；只有主动提交成绩时才联网（详见下） |
| **存档** | 最高分与语言偏好存在浏览器本地，不上传 |
| **引擎** | 零依赖 Canvas 2D 自研，无游戏框架；排行榜跑在 Cloudflare Worker + D1（可选） |

> 只有你**主动提交成绩**时才会联网，发出去的就是你自己填的昵称加这一局的成绩（分数、路程、时长、榜别）——没有账号、没有 cookie、没有其它标识。不提交就完全不联网；自建后端见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 玩法

**核心循环**：向前奔逐 → 越过龟裂焦土与深渊尖刺 → 拾「日光」升倍率、攒神力，掬「甘泉」续冲刺 → 疾冲撞碎旱魃、击退金乌 → 神力满时发「夸父跨步」一步跨一屏 → 在追来的「长夜」吞没你之前跑得更远。被长夜追上即结束一局。

**记分**：`功业 = 路程 × 倍率`。每拾一枚日光，倍率 +0.1（上限 ×3）；击杀与风格另有加分。路程越远、倍率越高，功业越大。

**神力与大招·夸父跨步**：拾日光与击杀积攒神力槽；满槽按 `K` 发动跨步——先腾空再横越一整屏，撞碎沿途一切，落地后 3 秒无敌，是脱困与冲分的关键。

**怪物**：`旱魃`（旱灾之鬼）与`金乌`（十日之乌）。疾冲或跨步中撞击可将其击杀得分；徒手触碰则死。

**景随事迁**：饮河渭段浮现水景、入日段热浪蒸腾、终章桃林渐显而日轮西沉。越过终章仍不停歇——**邓林月夜 → 大荒星野 → 曦光重临**，远行者方得一见。

**称号与分享**：按本局功业授予称号——`初出荒原` → `逐日者` → `饮河渭者` → `北饮大泽` → `夸父之志` → `与日齐光`。结算页按 `F` / 点上半屏生成成绩卡（结局图 + 功业 + 称号 + 网址），可直接分享。

## 模式

| 模式         | 说明                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| **常规无尽** | 地形逐局随机，逐日无尽，冲击「天下逐日榜」                                             |
| **今日挑战** | 全球同日同一种子、同一关卡，每次重来皆同一地图，独立成「今日挑战榜」每日刷新，同场竞逐 |

标题页按 `G` / 点屏幕上方切换模式；今日挑战横幅显示当日日期（按 UTC 日分派种子）。

## 操作

标题页按任意键 / 点触开始。触屏设备游玩时浮现一组半透明按钮（左手「退 / 进」，右手「跃 / 冲」，神力满时加一枚「跨」）。

| 操作                                   | 键盘                            | 触屏                                 |
| -------------------------------------- | ------------------------------- | ------------------------------------ |
| 左 / 右奔走                            | `←` `→` 或 `A` `D`              | 左下「退 / 进」                      |
| 腾跃（长按更高，含土狼时间与跳跃缓冲） | `Space` / `↑` / `W`             | 右下「跃」                           |
| 疾冲（八方向，落地或掬甘泉后刷新）     | `Shift` / `J`（配合方向键定向） | 右下「冲」                           |
| 夸父跨步（神力满·一步跨一屏·无敌）     | `K`                             | 神力满时右侧「跨」亮起，点按发动     |

其余按键在游戏里都有对应的牌可点，不必记：帮助 `H`、分享成绩 `F`、切换模式 `G`、切换语言 `T`、静音 `M`、死后重开 `R`。

> 隐藏秘籍·夸父不竭：连按三次「下」（`↓↓↓` 或 `S S S`）开启 / 关闭神力无限。

## 语言

支持 **简体中文 · 繁體中文 · English · 日本語 · 한국어**。首次进入按浏览器语言自动选定；在语言牌（或按 `T`）里亲自选过之后，这个选择优先于一切——别人分享给你的 `/ja/` 链接也盖不过它。

## 自己跑 / 自己部署

`npm install && npm run dev`，然后打开终端打印的地址（默认 <http://localhost:5173>）。本地测试、构建、部署（含排行榜 Worker）、引擎技术要点与目录结构见 **[DEVELOPMENT.md](DEVELOPMENT.md)**。
