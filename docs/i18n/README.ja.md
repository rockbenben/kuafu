> 北方に神あり、名を夸父といふ。力を量らず、日影を追はんとす。

シルエット風の荒野で夸父となり、永遠に追ひつけぬ太陽を逐ふ——日の光を拾つて倍率を上げ、甘泉を掬つて駆けを継ぎ、旱魃と金烏を砕き、石盾の向きを読んで背後を突き、神力満つれば一歩に一画面を跨ぐ。背後の長夜に呑まれる前に、どこまで遠く往けるか。

尋常の無尽走りとは異なり、天地は『山海経』の記載を一途に辿り終へる——暁の出立、河と渭を飲み、道半ばに渇き死し、杖を棄てて鄧林となる。終章を越えてなほ終らず、鄧林の月夜と大荒の星野は、遠くまで往きし者のみが見る。**この物語は局を跨いで積もる**——十二段は一局に収まらず、斃れても初めには戻らない。次の局は前回の続きから語り出す。

## 遊び方

**基本の流れ**：前へ駆ける → 罅割れた焦土と深淵・棘を越える → 「日光」を拾つて倍率を上げ神力を蓄へ、「甘泉」を掬つて駆けを継ぐ → 疾駆で旱魃を砕き金烏を退け、石盾には向きを読んで背後を突くか跳んで踏む → 途切れず斬れば連撃が積み上がる → 神力満つれば「夸父の跨歩」で一画面を跨ぐ → 追ひ来る「長夜」に呑まれる前に、より遠くへ。長夜に追ひつかれれば一局は終はる。

**採点**：`功業 = 道のり × 倍率`。日光を一つ拾ふごとに倍率 +0.1（上限 ×3）。撃破と所作にも加点あり。遠く往くほど、倍率高きほど、功業は大きい。

**神力と大技・夸父の跨歩**：日光と撃破で神力の槽が満ちる。満ちたら `K` で跨歩——まづ宙に浮き、次いで一画面を横切り、道中の一切を砕き、着地後 3 秒は無敵。窮地を脱し、点を伸ばす要である。

**敵**：`旱魃`（旱の鬼）と`金烏`（十日の烏）。疾駆または跨歩の最中に当たるか、落下しながら上から踏めば砕いて得点となるが、地上で走って当たれば死ぬ。

**石盾の旱魃**：石の盾を負ふ旱魃。正面は疾駆を弾く——ぶつかつても死なぬが、突き返されて速さを失ひ、駆けが暫し封じられる。長夜が間合ひを詰めるには十分だ。追つては来ず巡るのみ、盾は歩む側にあるゆゑ、**どちらへ歩いてゐるか**を見るのが読みの全て。背後から疾駆すれば「背刺」で得点は倍、跳んで上から踏むか跨歩なら常に通る。

**列を成す**：道を進めば、敵はもはや散り散りに立つてはをらぬ——三、四匹が一隊となつて待ち構へ、一匹づつではなく一組をまとめて解かねばならぬ。石盾も列も、しばし走らねば現れぬ。新たな敵が初めて姿を見せたときは、その攻め方を一言告げる。

**連撃と吹き飛ばし**：四秒のうちに斬り続ければ連撃が積もり、加点も増す（止め絵と震ひも重くなる）。疾駆と跨歩で斃した敵は吹き飛び、その骸は道すがら当たつた者を巻き込む——群れへ一度突つ込めば数体を連ねて薙ぐ。ただし石盾は飛来する骸も同じく弾く。正面から当てても砕けるだけゆえ、背後から回らねばならない。踏み潰しは下へ砕くゆゑ骸は飛ばぬ。

**いかにして死んだかを見る**：死は即座に画面を切り替へぬ。世界は止まり、鏡は寄り、人はその場に倒れ伏す。淵に墜つれば鏡も共に下り、いづれの溝に呑まれしかを見せる。まづ死の因が浮かび、やがて画は長夜に沈み、結局の絵と成績が闇より浮かび上がる。待てぬなら何かキーを押して飛ばせ。

**長夜迫る**：背後の長夜は速さを増し、遂には汝を上回る。ある間合ひまで迫れば画面の四隅が翳り、鼓動が加はる——近づくほど急かに打つ。鼓動を聞かば、道の日光を貪るを止めよ。

**情景は事に従ひ移ろふ**：河渭・大沢の段では水景が現れ、入日の段では熱波が立ち、終章では桃林が顕れ日輪が西に沈む。終章を越えてなほ止まず——**鄧林の月夜 → 大荒の星野 → 曦光の再臨**、遠く往きし者のみが見る。

**称号と分かち合ひ**：その一局の功業に応じて称号が与へられる——`荒野に出づ` → `逐日の者` → `河渭を飲む者` → `北のかた大沢を飲む` → `夸父の志` → `日と光を齊しくす`。結算画面で `F`（触屏なら上半分を押す）にて成績の札が成る（結局の絵＋功業＋称号＋網址）。そのまま分かてる。

**姿を変ふ**：題名画面にも結算画面にも「姿を変へる」がある。内には `玉兎` `応龍` `刑天` `羿` `飛天` `猫` の六つの影あり。「＋」を押さば己が画を人物と成すも得。**背景の透けたる PNG か SVG を勧む**——人物は地に立ち、影絵の景に重ねて描かるるゆゑ、白地の画は四角き板と成る。SVG は `viewBox` のみにて `width`/`height` なくとも正しく揃ふ。画は browser の手許にて縮められ、その手許に留まる——**送られはせぬ**。一枚きりの姿には走りの律動を機械が補ふ——振るるは脚のみ、頭は据ゑたるまま。宙にては伸び、疾走にては前へ傾く。されば己が顔を入れても、目に障らずそれらしく走る。

## モード

| モード         | 説明                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| **無尽**       | 地形は毎度あらたに、逐日は尽きず。「天下逐日の番付」を競ふ                               |
| **今日の試練** | 全世界で同じ日に同じ種・同じ関。何度やり直しても同じ地図。「今日の番付」として日毎に改まる |

題名画面で `G`（触屏なら画面上方を押す）にてモードを切り替へる。今日の試練の帯にはその日の日付が出る（種は UTC の日で配られる）。結算の画面には上位五名が並ぶ——汝が五指に入らば、その一行が灯る。

## 操作

題名画面では何かキーを押すか画面に触れれば始まる。触屏の機器では遊玩中に半透明の釦が並ぶ（左手に「退／進」、右手に「跳／駆」、神力満つれば「跨」が加はる）。

| 操作                                       | キーボード                        | タッチ                                 |
| ------------------------------------------ | --------------------------------- | -------------------------------------- |
| 左右に走る                                 | `←` `→` または `A` `D`            | 左下の「退／進」釦                     |
| 跳ぶ（長押しで高く、猶予と先行入力あり）   | `Space` / `↑` / `W`               | 右下の「跳」釦                         |
| 駆ける（八方向。着地か甘泉で回復）         | `Shift` / `J`（方向キーと併せて） | 右下の「駆」釦                         |
| 夸父の跨歩（神力満・一歩で一画面・無敵）   | `K`                               | 神力満つれば右の「跨」釦が灯る         |

その他の鍵はいづれもゲーム内に押せる牌があり、覚える必要はない：手引 `H`、成績を分かつ `F`、モード切替 `G`、言語切替 `T`、消音 `M`、死後にやり直す `R`。

> 隠し秘伝・夸父不竭：「下」を三度続けて押す（`↓↓↓` または `S S S`）と神力無尽が入切される。
