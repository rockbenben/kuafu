> 北方に神あり、名を夸父といふ。力を量らず、日影を追はんとす。

シルエット風の荒野で夸父となり、永遠に追ひつけぬ太陽を逐ふ——日の光を拾つて倍率を上げ、甘泉を掬つて駆けを継ぎ、旱魃と金烏を砕き、神力満つれば一歩に一画面を跨ぐ。背後の長夜に呑まれる前に、どこまで遠く往けるか。

尋常の無尽走りとは異なり、天地は『山海経』の記載を一途に辿り終へる——暁の出立、河と渭を飲み、道半ばに渇き死し、杖を棄てて鄧林となる。終章を越えてなほ終らず、鄧林の月夜と大荒の星野は、遠くまで往きし者のみが見る。

## 動く条件

| 項目 | 対応 |
| --- | --- |
| **機器** | 卓上（鍵盤）・携帯 / 板（画面上の触操作の釦）。縦に持てば、全景を得んがため横向きへ回すやう促す |
| **閲覧器** | 建置目標は ES2022——Chrome / Edge 94+、Safari 15.4+、Firefox 93+ |
| **導入** | 不要。頁を開けば遊べる——下載も、勘定も、登録も無し |
| **通信** | ゲームは終始ブラウザの中で動く。通信するのは自ら成績を送るときのみ（下に詳らか） |
| **保存** | 最高点と言語の好みはブラウザの手許に留まり、送られはせぬ |
| **engine** | 依存ゼロの自作 Canvas 2D、ゲームフレームワーク無し。順位表は Cloudflare Worker + D1（任意） |

> ゲーム本体は終始あなたのブラウザの中で動く。通信するのは**自ら成績を送信したとき**だけで、送られるのはあなたが入力した名と、その一局の成績（点・道のり・時間・番付の別）のみ——アカウントも cookie もその他の識別子も無い。送信しなければ一切通信しない。自前のバックエンドを立てる方法は [DEVELOPMENT.md](../../DEVELOPMENT.md) を見よ。

## 遊び方

**基本の流れ**：前へ駆ける → 罅割れた焦土と深淵・棘を越える → 「日光」を拾つて倍率を上げ神力を蓄へ、「甘泉」を掬つて駆けを継ぐ → 疾駆で旱魃を砕き金烏を退ける → 神力満つれば「夸父の跨歩」で一画面を跨ぐ → 追ひ来る「長夜」に呑まれる前に、より遠くへ。長夜に追ひつかれれば一局は終はる。

**採点**：`功業 = 道のり × 倍率`。日光を一つ拾ふごとに倍率 +0.1（上限 ×3）。撃破と所作にも加点あり。遠く往くほど、倍率高きほど、功業は大きい。

**神力と大技・夸父の跨歩**：日光と撃破で神力の槽が満ちる。満ちたら `K` で跨歩——まづ宙に浮き、次いで一画面を横切り、道中の一切を砕き、着地後 3 秒は無敵。窮地を脱し、点を伸ばす要である。

**敵**：`旱魃`（旱の鬼）と`金烏`（十日の烏）。疾駆または跨歩の最中に当たれば砕いて得点となるが、素手で触れれば死ぬ。

**情景は事に従ひ移ろふ**：河渭・大沢の段では水景が現れ、入日の段では熱波が立ち、終章では桃林が顕れ日輪が西に沈む。終章を越えてなほ止まず——**鄧林の月夜 → 大荒の星野 → 曦光の再臨**、遠く往きし者のみが見る。

**称号と分かち合ひ**：その一局の功業に応じて称号が与へられる——`荒野に出づ` → `逐日の者` → `河渭を飲む者` → `北のかた大沢を飲む` → `夸父の志` → `日と光を齊しくす`。結算画面で `F`、または上半分を押せば成績の札が成る（結局の絵＋功業＋称号＋網址）。そのまま分かてる。

## モード

| モード         | 説明                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| **無尽**       | 地形は毎度あらたに、逐日は尽きず。「天下逐日の番付」を競ふ                               |
| **今日の試練** | 全世界で同じ日に同じ種・同じ関。何度やり直しても同じ地図。「今日の番付」として日毎に改まる |

題名画面で `G`、または画面上方を押してモードを切り替へる。今日の試練の帯にはその日の日付が出る（種は UTC の日で配られる）。

## 操作

題名画面では何かキーを押すか画面に触れれば始まる。触屏の機器では遊玩中に半透明の釦が並ぶ（左手に「退／進」、右手に「跳／駆」、神力満つれば「跨」が加はる）。

| 操作                                       | キーボード                        | タッチ                                 |
| ------------------------------------------ | --------------------------------- | -------------------------------------- |
| 左右に走る                                 | `←` `→` または `A` `D`            | 左下の「退／進」釦                     |
| 跳ぶ（長押しで高く、猶予と先行入力あり）   | `Space` / `↑` / `W`               | 右下の「跳」釦                         |
| 駆ける（八方向。着地か甘泉で回復）         | `Shift` / `J`（方向キーと併せて） | 右下の「駆」釦                         |
| 夸父の跨歩（神力満・一歩で一画面・無敵）   | `K`                               | 神力満つれば右の「跨」釦が灯る         |

その他の鍵はいづれもゲーム内に押せる牌があり、覚える必要はない：手引 `H`、成績を分かつ `F`、モード切替 `G`、言語切替 `T`、消音 `M`、死後にやり直す `R`。

> 隠し秘伝・夸父不竭：「下」を三度続けて押す（`↓↓↓` または `S S S`）と神力無尽が入切される。
