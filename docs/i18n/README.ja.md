# 逐光 · 夸父逐日

> シルエット神話ランナー：夸父となり、決して追ひつけぬ日を逐ふ

> 北方に神あり、名を夸父といふ。力を量らず、日影を追はんとす。

シルエット風の荒野で夸父となり、永遠に追ひつけぬ太陽へ向かつて駆け続ける——日の光を拾つて力とし、甘泉を掬つて駆けを継ぎ、旱魃と金烏を砕き、神力満つれば夸父の跨歩で一歩に一画面を跨ぎ、背後の長夜に呑まれる前にどこまで遠く往けるか。情景は古籍の物語とともに移ろふ：暁の出立、入日の灼熱、河と渭を飲み、北のかた大沢へ、道半ばに渇き死し、杖を棄てて鄧林となるまで。終章を越えてなほ止まず、より深き記載に従ひ、鄧林の月夜・大荒の星野・曦光の再臨（逐日永く休まず）が展かれる。

## 遊び方

**基本の流れ**：前へ駆ける → 罅割れた焦土と深淵・棘を越える → 「日光」を拾つて倍率を上げ神力を蓄へ、「甘泉」を掬つて駆けを継ぐ → 疾駆で旱魃を砕き金烏を退ける → 神力満つれば「夸父の跨歩」で一画面を跨ぐ → 追ひ来る「長夜」に呑まれる前に、より遠くへ。

**採点**：`功業 = 道のり × 倍率`。日光を一つ拾ふごとに倍率 +0.1（上限 ×3）。撃破と所作にも加点あり。遠く往くほど、倍率高きほど、功業は大きい。

**神力と大技・夸父の跨歩**：日光と撃破で神力の槽が満ちる。満ちたら `K` で跨歩——まづ宙に浮き、次いで一画面を横切り、道中の一切を砕き、着地後 3 秒は無敵。窮地を脱し、点を伸ばす要である。

**敵**：`旱魃`（旱の鬼）と`金烏`（十日の烏）。疾駆または跨歩の最中に当たれば砕いて得点となるが、素手で触れれば死ぬ。

**情景は事に従ひ移ろふ**：天地は道のりと物語に従ひ一方向に進む——河渭・大沢の段では水景が現れ、入日の段では熱波が立ち、終章では桃林が次第に顕れ日輪が西に沈み、遂に杖は鄧林となる。**終章を越えてなほ止まず**：『大荒北経』『列子』陶淵明『読山海経』など、より深き夸父の記載に従ひ、天地は**鄧林の月夜 →（満天の星の）大荒の星野 → 曦光の再臨**へと続く（逐日永く休まず）。遠く往きし者のみが見る——陶潜の「余跡を鄧林に寄せ、功は身の後に在り」に収まり、本作の「功業」に正しく響く。

## 用語早見

夸父の神話を纏つてはゐるが、対応は至つて素直である：

| 用語            | ゲームでは何か                                                        |
| --------------- | --------------------------------------------------------------------- |
| **日光**        | 拾ふ光の粒——倍率上昇・神力蓄積・加点                                  |
| **甘泉**        | 拾へば駆けが一度回復する                                              |
| **神力**        | 大技の槽。満ちれば「夸父の跨歩」が放てる                              |
| **夸父の跨歩**  | 大技：宙に浮き一画面を横切り、道中を砕き、着地後 3 秒無敵             |
| **功業**        | あなたの点：`功業 = 道のり × 倍率 + 加点`                             |
| **旱魃 / 金烏** | 二種の敵（旱の鬼 / 十日の烏）——疾駆か跨歩で砕ける。素手で触れれば死ぬ |
| **長夜**        | 背後より迫る死の壁。追ひつかれれば一局は終はる                        |
| **鄧林 / 大荒** | 終章とその後の情景（桃林 / 星野の荒原）                               |

## モード

| モード         | 説明                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| **無尽**       | 地形は毎度あらたに、逐日は尽きず。「天下逐日の番付」を競ふ                               |
| **今日の試練** | 全世界で同じ日に同じ種・同じ関。何度やり直しても同じ地図。「今日の番付」として日毎に改まる |

題名画面で `G`、または画面上方を押してモードを切り替へる。今日の試練の帯にはその日の日付が出る（種は UTC の日で配られる）。

## 称号

その一局の功業に応じて称号が与へられ、結算画面に金色で題され、分かち合ひの札にも共に載る：

`荒野に出づ` → `逐日の者` → `河渭を飲む者` → `北のかた大沢を飲む` → `夸父の志` → `日と光を齊しくす`

## 操作

遊玩中、触屏の機器には半透明の釦が並ぶ（左手に「退／進」、右手に「跳／駆」、神力満つれば「跨」が浮かぶ）。

| 操作                                       | キーボード                        | タッチ                                 |
| ------------------------------------------ | --------------------------------- | -------------------------------------- |
| 左右に走る                                 | `←` `→` または `A` `D`            | 左下の「退／進」釦                     |
| 跳ぶ（長押しで高く、猶予と先行入力あり）   | `Space` / `↑` / `W`               | 右下の「跳」釦                         |
| 駆ける（八方向。着地か甘泉で回復）         | `Shift` / `J`（方向キーと併せて） | 右下の「駆」釦                         |
| 夸父の跨歩（神力満・一歩で一画面・無敵）   | `K`                               | 神力満つれば右の「跨」釦が灯る         |
| 手引の浮層（一時停止）                     | `H`                               | 題名画面左下の「手引」牌。画面を押せば閉づ |
| 成績を分かつ（結算画面）                   | `F`                               | 結算画面の上半分を押す                 |
| モード切替（無尽／今日の試練）             | `G`                               | 題名画面の上方を押す                   |
| 言語切替（五語種）                         | `T` で開合、`1`~`5` で直に選ぶ    | 題名・結算画面右下の「言語」牌         |
| 消音                                       | `M`                               | 手引の浮層内の「音」釦                 |
| 死後にやり直す                             | `R` / `Space`                     | 結算画面の下半分を押す                 |

題名画面では何かキーを押すか画面に触れれば始まる。端末を縦に持つと、横に回すやう促される。

題名画面の左右の下隅には牌が一枚づつある（左は「? 手引」、右は「地球＋現在の言語」）。**マウスでもタッチでも押せる**。キーボードの機器では牌に `H` / `T` の別も記される。結算画面の右下にも言語牌がある。

## 言語

**简体中文 · 繁體中文 · English · 日本語 · 한국어** の五語種に対応する。題名画面と結算画面の右下に言語牌（地球の図＋現在の言語）があり、押せば献立が開く。卓上機では `T` でも開き、`1`~`5` で直に選べる。

初回は閲覧器の言語で自動に選ばれ、変へられる旨を一度だけ告げる。**献立で自ら選んだ後は、その選択が一切に優先する**——人から分かたれた `/ja/` の連結も、`?lang=` を帯びた住所も、それを覆せない。自ら選ぶ前に限り、連結の語種が効く。

各語種には独立した頁が予め算繪されてゐる（`/`、`/en/`、`/ja/`、`/ko/`、`/zh-Hant/`）。それぞれ本地化された題・説明・分かち合ひの札を持ち、互ひに `hreflang` で指し合ふ。

『山海経』の古文の旁白は、外語では意訳とし、出典を別行に記す。逐字の直訳ではなく、その古意を存することを旨とする。

> 隠し秘伝・夸父不竭：「下」を三度続けて押す（`↓↓↓` または `S S S`）と神力無尽が入切される。

## 一押しで分かつ

結算画面で `F`、または上半分を押せば成績の札が成る（結局の絵＋功業＋称号＋標語＋網址）。携帯では系統の分かち合ひ面板を通し（なるべく絵も添へ）、卓上では文案を写し取り札を降ろす。
