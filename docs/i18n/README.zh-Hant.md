> 北方有神，名曰夸父，不量力，欲追日影。

在剪影風的荒原上化身夸父，追一輪永遠追不上的太陽：拾日光升倍率、掬甘泉續衝刺、撞碎旱魃與金烏、神力滿時一步跨過整屏，在身後的長夜吞沒你之前跑得更遠。

和一般的無盡跑酷不同——天地會跟著《山海經》的記載一路走完：拂曉啟程、飲於河渭、道渴而死、棄杖化為鄧林。越過終章還沒有完，鄧林月夜與大荒星野只有跑得夠遠的人見得到。

## 玩法

**核心循環**：向前奔逐 → 越過龜裂焦土與深淵尖刺 → 拾「日光」升倍率、攢神力，掬「甘泉」續衝刺 → 疾衝撞碎旱魃、擊退金烏 → 神力滿時發「夸父跨步」一步跨一屏 → 在追來的「長夜」吞沒你之前跑得更遠。被長夜追上即結束一局。

**記分**：`功業 = 路程 × 倍率`。每拾一枚日光，倍率 +0.1（上限 ×3）；擊殺與風格另有加分。路程越遠、倍率越高，功業越大。

**神力與大招·夸父跨步**：拾日光與擊殺積攢神力槽；滿槽按 `K` 發動跨步——先騰空再橫越一整屏，撞碎沿途一切，落地後 3 秒無敵，是脫困與衝分的關鍵。

**怪物**：`旱魃`（旱災之鬼）與`金烏`（十日之烏）。疾衝或跨步中撞擊可將其擊殺得分；徒手觸碰則死。

**長夜將至**：身後的長夜越追越快，終究快過你。它逼近到一定距離時，畫面四周漸暗、心跳隨之加急——離得越近跳得越急。聽見心跳就別再貪路上的日光了。

**景隨事遷**：飲河渭段浮現水景、入日段熱浪蒸騰、終章桃林漸顯而日輪西沉。越過終章仍不停歇——**鄧林月夜 → 大荒星野 → 曦光重臨**，遠行者方得一見。

**稱號與分享**：按本局功業授予稱號——`初出荒原` → `逐日者` → `飲河渭者` → `北飲大澤` → `夸父之志` → `與日齊光`。結算頁按 `F`（觸控點上半螢幕）生成成績卡（結局圖 + 功業 + 稱號 + 網址），可直接分享。

**換個形象**：標題頁與結算頁都有「換個形象」，內建 `玉兔` `應龍` `刑天` `后羿` `飛天` `狸奴` 六種剪影；也可以點「＋」傳自己的圖當角色——圖片在瀏覽器本機縮放後存在本機，**不會上傳**。單幀形象由程式補上奔跑律動——擺的是腿、頭頸幾乎不動，另有騰空拉伸與衝刺前傾，所以傳張自己的照片進去也跑得有模有樣，且不會看得眼暈。

## 模式

| 模式         | 說明                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| **常規無盡** | 地形逐局隨機，逐日無盡，衝擊「天下逐日榜」                                             |
| **今日挑戰** | 全球同日同一種子、同一關卡，每次重來皆同一地圖，獨立成「今日挑戰榜」每日刷新，同場競逐 |

標題頁按 `G`（觸控點螢幕上方）切換模式；今日挑戰橫幅顯示當日日期（按 UTC 日分派種子）。結算頁列出榜前五名——你若進了前五，自己那一行會點亮。

## 操作

標題頁按任意鍵 / 點觸開始。觸控裝置遊玩時浮現一組半透明按鈕（左手「退 / 進」，右手「躍 / 衝」，神力滿時加一枚「跨」）。

| 操作                                   | 鍵盤                            | 觸控                                    |
| -------------------------------------- | ------------------------------- | --------------------------------------- |
| 左 / 右奔走                            | `←` `→` 或 `A` `D`              | 左下「退 / 進」按鈕（進為主碟、退為輔） |
| 騰躍（長按更高，含土狼時間與跳躍緩衝） | `Space` / `↑` / `W`             | 右下「躍」按鈕                          |
| 疾衝（八方向，落地或掬甘泉後刷新）     | `Shift` / `J`（配合方向鍵定向） | 右下「衝」按鈕                          |
| 夸父跨步（神力滿·一步跨一屏·無敵）     | `K`                             | 神力滿時右側「跨」按鈕亮起，點按發動    |

其餘按鍵在遊戲裡都有對應的牌可點，不必記：幫助 `H`、分享成績 `F`、切換模式 `G`、切換語言 `T`、靜音 `M`、死後重開 `R`。

> 隱藏秘籍·夸父不竭：連按三次「下」（`↓↓↓` 或 `S S S`）開啟 / 關閉神力無限。
