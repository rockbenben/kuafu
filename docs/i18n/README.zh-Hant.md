> 北方有神，名曰夸父，不量力，欲追日影。

在剪影風的荒原上化身夸父，向著永遠追不上的太陽一路狂奔——拾日光壯行、掬甘泉續力、撞碎旱魃金烏、發夸父跨步一步跨一屏，在身後的長夜吞沒你之前跑得更遠。場景隨古籍敘事景隨事遷：從拂曉啟程、入日灼熱、飲於河渭、北飲大澤、道渴而死，到棄杖化為鄧林；越過終章仍不停歇，隨更深的記載展開鄧林月夜、大荒星野、曦光重臨（逐日永不休）。

![標題](../images/screenshot-title.webp)

**▶ 線上試玩**：<https://kuafu.newzone.top>　·　**本地執行**：`npm install && npm run dev`，然後開啟終端印出的位址（預設 <http://localhost:5173>）。

## 玩法

**核心循環**：向前奔逐 → 越過龜裂焦土與深淵尖刺 → 拾「日光」升倍率、攢神力，掬「甘泉」續衝刺 → 疾衝撞碎旱魃、擊退金烏 → 神力滿時發「夸父跨步」一步跨一屏 → 在追來的「長夜」吞沒你之前跑得更遠。

**記分**：`功業 = 路程 × 倍率`。每拾一枚日光，倍率 +0.1（上限 ×3）；擊殺與風格另有加分。路程越遠、倍率越高，功業越大。

**神力與大招·夸父跨步**：拾日光與擊殺積攢神力槽；滿槽按 `K` 發動跨步——先騰空再橫越一整屏，撞碎沿途一切，落地後 3 秒無敵，是脫困與衝分的關鍵。

**怪物**：`旱魃`（旱災之鬼）與`金烏`（十日之烏）。疾衝或跨步中撞擊可將其擊殺得分；徒手觸碰則死。

**景隨事遷**：天地隨路程與敘事單向推進——飲河渭/大澤段浮現水景、入日段熱浪蒸騰、終章桃林漸顯日輪西沉，直至棄杖化為鄧林。**越過終章仍不停歇**：隨《大荒北經》《列子》陶淵明《讀山海經》等更深的夸父記載，天地續展為**鄧林月夜 →（滿天星子的）大荒星野 → 曦光重臨**（逐日永不休），遠行者方得一見——收束於陶潛「餘跡寄鄧林，功竟在身後」，正扣本作「功業」。

## 術語速查

遊戲借夸父神話包裝，術語對照其實很直白：

| 術語            | 在遊戲裡是什麼                                                      |
| --------------- | ------------------------------------------------------------------- |
| **日光**        | 拾取的光點——升倍率、攢神力、加分                                    |
| **甘泉**        | 拾取即刷新一次衝刺                                                  |
| **神力**        | 大招能量槽，滿了可發「夸父跨步」                                    |
| **夸父跨步**    | 大招：先騰空再橫越一整屏，撞碎沿途、落地 3 秒無敵                   |
| **功業**        | 你的分數：`功業 = 路程 × 倍率 + 加分`                               |
| **旱魃 / 金烏** | 兩種敵人（旱災之鬼 / 十日之烏）——衝刺或跨步撞擊可擊殺，徒手觸碰即死 |
| **長夜**        | 身後逼近的死亡之牆，被追上即結束一局                                |
| **鄧林 / 大荒** | 終章及其後的場景（桃林 / 星野荒原）                                 |

## 模式

| 模式         | 說明                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| **常規無盡** | 地形逐局隨機，逐日無盡，衝擊「天下逐日榜」                                             |
| **今日挑戰** | 全球同日同一種子、同一關卡，每次重來皆同一地圖，獨立成「今日挑戰榜」每日刷新，同場競逐 |

標題頁按 `G` / 點螢幕上方切換模式；今日挑戰橫幅顯示當日日期（按 UTC 日分派種子）。

## 操作

遊玩時觸控裝置顯示一組半透明按鈕（左手「退 / 進」，右手「躍 / 衝」，神力滿時浮現「跨」）。

| 操作                                   | 鍵盤                            | 觸控                                    |
| -------------------------------------- | ------------------------------- | --------------------------------------- |
| 左 / 右奔走                            | `←` `→` 或 `A` `D`              | 左下「退 / 進」按鈕（進為主碟、退為輔） |
| 騰躍（長按更高，含土狼時間與跳躍緩衝） | `Space` / `↑` / `W`             | 右下「躍」按鈕                          |
| 疾衝（八方向，落地或掬甘泉後刷新）     | `Shift` / `J`（配合方向鍵定向） | 右下「衝」按鈕                          |
| 夸父跨步（神力滿·一步跨一屏·無敵）     | `K`                             | 神力滿時右側「跨」按鈕亮起，點按發動    |
| 幫助浮層（暫停）                       | `H`                             | 標題頁左下「幫助」牌；點螢幕關閉        |
| 分享成績（結算頁）                     | `F`                             | 結算頁點上半螢幕                        |
| 切換模式（常規 / 今日挑戰）            | `G`                             | 標題點螢幕上方                          |
| 切換語言（五語種）                     | `T` 開合選單，`1`~`5` 直選      | 標題頁 / 結算頁右下「語言」牌           |
| 靜音                                   | `M`                             | 幫助浮層內「聲音」鈕                    |
| 死亡後重開                             | `R` / `Space`                   | 結算頁點下半螢幕                        |

標題頁按任意鍵 / 點觸開始。豎持手機會提示旋轉橫屏以獲得完整視野。

標題頁左右下角各有一枚牌（左「? 幫助」、右「地球 + 當前語言」），**滑鼠、觸控都可點**；鍵盤端牌上還標著對應的 `H` / `T`。結算頁右下角也有一枚語言牌。

## 語言

支援 **简体中文 · 繁體中文 · English · 日本語 · 한국어** 五個語種。標題頁與結算頁右下角各有一枚語言牌（地球圖示 + 當前語言），點它開選單；桌面端也可按 `T`，選單裡 `1`~`5` 直選。

首次進入按瀏覽器語言自動選定，並提示一次可改。**你在選單裡親自選過之後，這個選擇優先於一切**——別人分享給你的 `/ja/` 連結或帶 `?lang=` 的位址都蓋不過它。還沒親選過時，連結裡的語種才生效。

站點為每個語種預先算繪了獨立頁面（`/`、`/en/`、`/ja/`、`/ko/`、`/zh-Hant/`），各自帶本地化的標題、描述與分享卡，彼此以 `hreflang` 互指。

《山海經》古文旁白在外語下作意譯並另起一行標註出處，力求存其古意而非逐字直譯。

> 隱藏秘籍·夸父不竭：連按三次「下」（`↓↓↓` 或 `S S S`）開啟/關閉神力無限。

## 一鍵分享

結算頁 `F` / 點上半螢幕即產生成績卡（結局圖 + 功業 + 稱號 + 標語 + 網址）：行動端走系統原生分享面板（盡量帶圖），桌面端複製分享文案並下載成績卡。
