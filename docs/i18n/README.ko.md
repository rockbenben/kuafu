# 빛을 좇다 · 과보축일

> 실루엣 신화 러너: 과보가 되어, 결코 닿을 수 없는 해를 좇다

[简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

> 북방에 신이 있어 이름을 과보라 하니, 힘을 헤아리지 않고 해를 좇았다.

실루엣 풍의 거친 들에서 과보가 되어, 영영 닿을 수 없는 해를 향해 내달린다 — 햇빛을 거두어 힘을 얻고, 샘물을 떠 질주를 잇고, 한발과 금오를 부수고, 신력이 차면 과보의 도보로 한 걸음에 한 화면을 건너뛰며, 뒤에서 다가오는 긴 밤에 삼켜지기 전에 얼마나 멀리 갈 수 있는가. 풍경은 옛 기록의 서사를 따라 옮겨간다: 새벽의 출발, 해에 들어선 뜨거움, 황하와 위수를 마시고, 북으로 대택으로, 길에서 목말라 죽고, 지팡이를 던져 등림이 되기까지. 마지막 장을 넘어서도 멈추지 않고, 더 깊은 기록을 따라 등림의 달밤, 대황의 별벌판, 서광의 재림(축일은 영영 쉬지 않는다)이 펼쳐진다.

![제목](../images/screenshot-title.webp)

**▶ 온라인 플레이**: <https://kuafu.newzone.top>　·　**로컬 실행**: `npm install && npm run dev` 후 터미널에 표시된 주소를 연다(기본 <http://localhost:5173>).

의존성 없는 자체 Canvas 2D 엔진. 게임 프레임워크도, 런타임 그래픽 라이브러리도 쓰지 않는다. 온라인 순위표는 Cloudflare Worker + D1 위에서 돈다(선택).

> 게임 자체는 처음부터 끝까지 당신의 브라우저 안에서 돈다. 네트워크를 쓰는 것은 **직접 기록을 제출할 때**뿐이며, 나가는 것은 당신이 입력한 닉네임과 그 판의 기록(점수·노정·시간·순위표 구분)뿐이다 — 계정도, 쿠키도, 다른 식별자도 없다. 제출하지 않으면 전혀 통신하지 않는다. 자체 백엔드를 세우려면 [DEVELOPMENT.md](../../DEVELOPMENT.md)를 보라.

## 플레이 방법

**핵심 흐름**: 앞으로 달린다 → 갈라진 땅과 심연·가시를 넘는다 → 「햇빛」을 거두어 배율을 올리고 신력을 쌓고, 「샘물」을 떠 질주를 잇는다 → 질주로 한발을 부수고 금오를 물리친다 → 신력이 차면 「과보의 도보」로 한 화면을 건넌다 → 뒤쫓는 「긴 밤」에 삼켜지기 전에 더 멀리.

**점수**: `공업 = 노정 × 배율`. 햇빛을 하나 거둘 때마다 배율 +0.1(최대 ×3). 처치와 몸놀림에도 가점이 있다. 멀리 갈수록, 배율이 높을수록 공업은 커진다.

**신력과 필살기·과보의 도보**: 햇빛과 처치로 신력 게이지가 찬다. 가득 차면 `K`로 도보 — 먼저 공중으로 떠오른 뒤 한 화면을 가로지르며 길목의 모든 것을 부수고, 착지 후 3초간 무적이다. 위기를 벗어나고 점수를 밀어 올리는 열쇠다.

**적**: `한발`(가뭄의 귀신)과 `금오`(열 개의 해의 까마귀). 질주나 도보 중에 부딪히면 부수어 점수가 되지만, 맨몸으로 닿으면 죽는다.

**풍경은 일을 따라 옮겨간다**: 하늘과 땅은 노정과 서사를 따라 한 방향으로 나아간다 — 황하·위수와 대택 구간에서는 물빛이 떠오르고, 해에 들어선 구간에서는 열기가 아지랑이처럼 피어오르며, 마지막 장에서는 복숭아 숲이 차츰 드러나고 해가 서쪽으로 기울어, 마침내 지팡이는 등림이 된다. **마지막 장을 넘어서도 멈추지 않는다**: 『대황북경』, 『열자』, 도연명 『독산해경』 등 더 깊은 과보의 기록을 따라 천지는 **등림의 달밤 →(별이 가득한) 대황의 별벌판 → 서광의 재림**으로 이어진다(축일은 영영 쉬지 않는다). 멀리 간 자만이 본다 — 도잠의 「자취는 등림에 남고 공은 뒤에 이루다」로 맺히며, 이 작품의 「공업」에 그대로 울린다.

## 용어 한눈에

과보 신화를 두르고 있지만 대응은 사뭇 단순하다:

| 용어             | 게임에서는 무엇인가                                                    |
| ---------------- | ---------------------------------------------------------------------- |
| **햇빛**         | 주워 모으는 빛 알갱이 — 배율 상승·신력 축적·가점                       |
| **샘물**         | 주우면 질주가 한 번 회복된다                                           |
| **신력**         | 필살기 게이지. 가득 차면 「과보의 도보」를 쓸 수 있다                  |
| **과보의 도보**  | 필살기: 떠올라 한 화면을 가로지르며 길목을 부수고, 착지 후 3초 무적    |
| **공업**         | 당신의 점수: `공업 = 노정 × 배율 + 가점`                               |
| **한발 / 금오**  | 두 종류의 적(가뭄의 귀신 / 열 해의 까마귀) — 질주·도보로 부술 수 있고, 맨몸으로 닿으면 죽는다 |
| **긴 밤**        | 뒤에서 다가오는 죽음의 벽. 따라잡히면 한 판이 끝난다                   |
| **등림 / 대황**  | 마지막 장과 그 이후의 풍경(복숭아 숲 / 별벌판의 황야)                  |

## 모드

| 모드            | 설명                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| **무한**        | 지형은 판마다 새로이, 축일은 끝이 없다. 「천하 축일 순위」를 겨룬다                        |
| **오늘의 시련** | 전 세계가 같은 날 같은 씨앗·같은 관문. 몇 번을 다시 해도 같은 지도. 「오늘의 순위」로 날마다 새로워진다 |

제목 화면에서 `G`를 누르거나 화면 위쪽을 눌러 모드를 바꾼다. 오늘의 시련 띠에는 그날의 날짜가 나온다(씨앗은 UTC 날짜로 배포된다).

## 칭호

그 판의 공업에 따라 칭호가 주어지고, 결산 화면에 금빛으로 새겨지며, 공유 카드에도 함께 실린다:

`거친 들에 나서다` → `해를 좇는 자` → `황하와 위수를 마신 자` → `북으로 대택을 마시다` → `과보의 뜻` → `해와 빛을 나란히`

## 조작

플레이 중 터치 기기에는 반투명한 버튼이 나온다(왼손에 「뒤 / 앞」, 오른손에 「도약 / 질주」, 신력이 차면 「도보」가 떠오른다).

| 조작                                       | 키보드                            | 터치                                   |
| ------------------------------------------ | --------------------------------- | -------------------------------------- |
| 좌 / 우로 달리기                           | `←` `→` 또는 `A` `D`              | 왼쪽 아래 「뒤 / 앞」 버튼             |
| 도약(길게 누르면 더 높이, 유예와 선입력 있음) | `Space` / `↑` / `W`            | 오른쪽 아래 「도약」 버튼              |
| 질주(8방향, 착지하거나 샘물로 회복)        | `Shift` / `J`(방향키와 함께)      | 오른쪽 아래 「질주」 버튼              |
| 과보의 도보(신력 가득·한 걸음에 한 화면·무적) | `K`                             | 신력이 차면 오른쪽 「도보」 버튼이 켜진다 |
| 도움말 오버레이(일시정지)                  | `H`                               | 제목 화면 왼쪽 아래 「도움말」 버튼    |
| 기록 공유(결산 화면)                       | `F`                               | 결산 화면 위쪽 절반을 누른다           |
| 모드 전환(무한 / 오늘의 시련)              | `G`                               | 제목 화면 위쪽을 누른다                |
| 언어 전환(다섯 가지)                       | `T`로 여닫고 `1`~`5`로 바로 선택  | 제목·결산 화면 오른쪽 아래 「언어」 버튼 |
| 음소거                                     | `M`                               | 도움말 오버레이 안의 「소리」 버튼     |
| 죽은 뒤 다시 시작                          | `R` / `Space`                     | 결산 화면 아래쪽 절반을 누른다         |

제목 화면에서 아무 키나 누르거나 화면을 터치하면 시작된다. 기기를 세로로 들면 가로로 돌리라는 안내가 나온다.

제목 화면 좌우 아래 모서리에는 각각 버튼이 하나씩 있다(왼쪽은 「? 도움말」, 오른쪽은 「지구본 + 현재 언어」). **마우스와 터치 모두 누를 수 있으며**, 키보드 기기에서는 버튼에 `H` / `T` 키도 함께 표시된다. 결산 화면 오른쪽 아래에도 언어 버튼이 있다.

## 언어

**简体中文 · 繁體中文 · English · 日本語 · 한국어** 다섯 가지를 지원한다. 제목 화면과 결산 화면 오른쪽 아래에 언어 버튼(지구본 아이콘 + 현재 언어)이 있으며, 누르면 메뉴가 열린다. 데스크톱에서는 `T`로도 열 수 있고, 메뉴에서 `1`~`5`로 바로 고를 수 있다.

처음 들어오면 브라우저 언어로 자동 선택되고, 바꿀 수 있다는 안내가 한 번 뜬다. **메뉴에서 직접 고른 뒤에는 그 선택이 무엇보다 우선한다** — 남이 공유한 `/ja/` 링크도, `?lang=`이 붙은 주소도 그것을 덮지 못한다. 직접 고르기 전에만 링크의 언어가 적용된다.

사이트는 언어마다 독립된 페이지를 미리 렌더링해 둔다(`/`, `/en/`, `/ja/`, `/ko/`, `/zh-Hant/`). 각각 현지화된 제목·설명·공유 카드를 가지며, 서로 `hreflang`으로 가리킨다.

『산해경』 고문 내레이션은 외국어에서는 의역하고 출전을 다음 줄에 밝힌다. 글자 그대로의 직역이 아니라 그 옛맛을 지키는 것을 목표로 한다.

> 숨은 비전·과보불갈: 「아래」를 세 번 연달아 누르면(`↓↓↓` 또는 `S S S`) 신력 무한이 켜지고 꺼진다.

## 한 번에 공유

결산 화면에서 `F`를 누르거나 위쪽 절반을 누르면 기록 카드가 만들어진다(결말 그림 + 공업 + 칭호 + 표어 + 주소). 모바일에서는 시스템 공유 시트를 거치고(가능하면 이미지도 함께), 데스크톱에서는 공유 문구를 복사하고 카드를 내려받는다.
